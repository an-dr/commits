# Progress

**Flow:** Detailed
**Phase:** COMMIT
**Goal:** Let the installed Commits app integrate with the OS on explicit user action: Windows Explorer "Open in Commits" on folders and folder backgrounds plus Start Menu/desktop shortcuts; Linux (Ubuntu, Pop!_OS) app-launcher entry that is also the "Open With" target for folders. Registration and removal are explicit UI actions, and an unregistered app is effectively portable.
**Done when:** On Windows, Install and register in a portable run creates shortcuts and the folder/background "Open in Commits" verbs that open that folder in Commits; Unregister in an installed run removes all of them and leaves ~/.commits/app intact. On Linux, the same actions create/remove a .desktop entry visible in the app menu and in the folder "Open With" list in Nautilus/COSMIC Files. The menu shows the correct action for the detected state. Crate unit tests cover generated registry/desktop content and register/unregister idempotence against a scratch location; docs (updating.md, a new integration doc, index) describe it; install.ps1 no longer creates shortcuts.
**Constraints:** No settings entry; menu actions only. Register/Unregister appear only in an installed run and always target ~/.commits/app/commits(.exe). Install from a non-installed run registers too, labelled explicitly. Unregister removes only OS registration and never deletes files. Windows uses per-user HKCU classic verbs (no admin). Linux uses ~/.local/share/applications .desktop with MimeType=inode/directory and a committed 256px PNG icon. Logic lives in a self-contained crate with no repository dependency so it can move to bones later (ADR-012). install.ps1 only copies files. vendor/bones stays untouched (ADR-003). Bump app and launcher version at integration.
**Out of scope:** Windows 11 top-level context menu (sparse MSIX + IExplorerCommand); drive context menu; Nautilus scripts/extensions or direct right-click items on Linux; macOS; deleting files on unregister (no uninstaller); registering portable copies; a settings entry; the bones upstream move itself (follow-up).

## Requests

- Windows: add an Explorer context-menu entry on folders (and folder background) that opens the folder in Commits
- Ubuntu / Pop!_OS: make Commits appear in "Open With" for folders (file manager integration)
- UI buttons (not a setting) to Register / Unregister the app with the OS: register = shortcuts + launcher entry + folder integration; unregister removes all of it and leaves the executables where they are, so the app is effectively portable
- Linux: a launcher (app menu) entry, which is also the Open With target for folders
- System integration logic lives where it can be reused (candidate for bones upstream, per ADR-012)
