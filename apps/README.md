# Applications

Complete, runnable products built from this repository. Each subdirectory is one
application and owns everything specific to it: its executable, its adapters to
whatever engine it runs on, its user interface, and its build scripts.

A file belongs here when it exists only because this application exists. Code
that another host could reuse belongs in `packages/` when it is TypeScript, or
`crates/` when it is Rust.
