# Commits 1.9.0

This version is prepared for release. Publishing still requires the verified commit on `main` and the matching `v1.9.0` tag.

- Single instance: subsequent launches open repositories in the existing window, including launches received during loading.
- Navigation flags: `--show changes|conflicts|graph`, `--branch`, and `--commit`, with best-effort selection and non-modal notices.
- Session appearance: `--theme light|dark` and `--theme-file`, without changing saved settings.
- Repository health: a compact clickable verdict with a published rule table and conformance vectors.
- Repository sources: caller-provided, grouped and favorited repository lists in the selector.
- Bones engine 2.0.0 migration: native desktop registration, upgrade, program launching, folder watching, and the development control channel replace local implementations.

Contracts: [command line](../command-line.md), [health](../repository-health.md), [vectors](../repository-health.vectors.json), [sources](../repository-sources.md), and [themes](../themes.md).

The app currently pins upstream Bones commit `0afba309c4338466b180dc39f9e7c2df0b240cba`; its release tag will be adopted separately. The page server remains local because this Bones version does not include asynchronous HTML-panel serving. The launcher uses `--previous` for recovery and delegates installation mutations to the app's upgrade module.
